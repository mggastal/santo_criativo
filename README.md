# santo_criativo

Central de dashboards da Santo Criativo: https://mggastal.github.io/santo_criativo/

- clientes.json: lista de clientes (grupo ativo / politica / inativo, planilha, logo)
- coletar.py: lê as planilhas + último commit de cada dash e grava status.json (Action de hora em hora)
- logos/: cópias pequenas dos logos
